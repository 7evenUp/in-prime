# Crypton Prime — портфолио

Автономная демонстрация старого проекта. API заменён локальными данными и графикой из репозитория. База данных, сервер API и переменные окружения для запуска не нужны.

## Запуск

```sh
pnpm install
pnpm dev
```

## Функциональность

Кнопка покупки сразу показывает успешное оформление выбранной подписки. Форм авторизации, платёжных счетов и личного кабинета нет. Праздничные кейсы можно открывать сколько угодно: рулетка каждый раз выбирает случайный подарок. Данные пользователя, покупки и подарки не сохраняются. Примеры заработка, дорожная карта и остальные интерактивные секции используют исходный контент.

Переключатель сверху открывает шесть вариантов:

- **Последний актуальный вариант** — последний сохранённый лендинг текущего репозитория.
- **До сентября 2023** — снимок `a0acb3b` от 25.08.2023.
- **Редизайн · октябрь–ноябрь 2023** — снимок `88207ad` от 03.11.2023 с оригинальной дорожной картой по заработку.
- **День рождения**, **Новый год**, **Чёрная пятница** — композиции из сохранившихся праздничных компонентов и графики. Таймер показывает демонстрационную акцию на семь дней.

Версия задаётся параметром адреса, например `/?version=redesign`. При открытии без параметра показывается последний актуальный вариант. Внешние социальные ссылки сохранены как часть оригинального контента.

Архивы имеют отдельные стили и графику. Воспроизвести их из истории Git можно через `node scripts/prepare-legacy.cjs` и `node scripts/prepare-redesign.cjs`; для обычного запуска это не требуется.

## Проверки

```sh
pnpm typecheck
pnpm test
pnpm build
```

`demo/api.ts` содержит локальный адаптер без сетевого fallback и сохранения состояния. `demo/fixtures.ts` — данные кейсов, подписок и подарков. `demo/Toolbar.tsx` — переключатель. `demo/legacy` и `demo/redesign` — исторические снимки.

Проект сохраняет Next.js 13.5.1 и React 18 из репозитория.
